# brutal-age-backend

Brutal Age AB's Marketplace — Backend Express Microservices API & MongoDB Atlas Pipeline

## Overview
- **Framework**: Node.js & Express.js
- **Database**: MongoDB Atlas Production Cluster
- **Authentication**: JWT & Bcrypt 256-Bit Cryptographic Hashing
- **Cybersecurity**: Helmet Security Headers, Anti-NoSQL Query Sanitization, Anti-XSS Script Shield
- **Image Pipeline**: Google Firebase Storage Bucket (`ab-s-marketplace.firebasestorage.app`)

## Deployment
- Configured for 1-Click deployment on Render via `render.yaml` Blueprint.
